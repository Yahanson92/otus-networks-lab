# Мультирегиональная корпоративная сеть (L2/L3 Топология)

## Описание проекта
Стенд развернут в среде EVE-NG на базе образов **Cisco IOL3**. Проект представляет собой сложно-сегментированную сеть с несколькими автономными системами, резервированием на уровне ядра и распределения, а также изолированным Management-сегментом для управления L2-инфраструктурой.

### Ключевые особенности стенда:
* **Защита от пересечений сетей (overlaps):** Все транзитные P2P-линки жестко сегментированы маской `/30`.
* **Управление (Management VLAN 99):** Разнесено на 3 изолированные подсети (Москва, СПб, Чокурдах) с настроенными L3-шлюзами на маршрутизаторах и `default-gateway` на коммутаторах.
* **Изоляция пользователей:** Клиентские ПК вынесены в отдельные VLAN с терминацией на сабинтерфейсах (Router-on-a-Stick).

## Инструкция по развертыванию
1. Собрать логическую топологию в EVE-NG.
2. Применить монолитный конфигурационный файл из директории `configs/` к узлам. Файл содержит команды `default interface range` для безопасной перезаписи портов без конфликтов IP.
3. Сохранить конфигурацию на устройствах (`wr`).
