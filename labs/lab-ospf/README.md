В данной лабораторной работе реализована многоуровневая архитектура OSPF для московского филиала. 

## Топология и зоны
- **Area 0 (Backbone):**  ядро сети. На стыке стоят роутеры **R14** и **R15**. Поскольку прямого физического линка между ними нет, между ними поднят `virtual-link` через транзитную зону 10.
- **Area 10:** Рабочая зона шлюзов **R12** и **R13**. Они смотрят вниз на пользовательские сети и забирают маршрут по умолчанию (`0.0.0.0/0`) от пограничных роутеров. На сабинтерфейсах включен `passive-interface`, чтобы не гонять лишний служебный трафик в пользовательские VLAN.
- **Area 101 (Stub):** Тупиковая зона для роутера **R19**. 
- **Area 102:**  зона для роутера **R20**. По условию задания R20 должен видеть всю сеть, кроме зоны 101. Для этого на пограничном роутере **R15** настроен `prefix-list`, который вырезает анонсы зоны 101 при отправке трафика в сторону R20.

Все настройки  собраны в  файле `configs_ospf.txt`.
